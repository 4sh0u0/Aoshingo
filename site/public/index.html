歩行者用信号を、
手のひらに。

Aoshingo（青信号）は、交差点の信号機が発信する Bluetooth 信号を受け取り、歩行者用信号の状態を iPhone に表示して読み上げるアプリです。

  • 使い方を見る
  • GitHub

できること

見えにくくても、わかるように。

  • 約600か所

    全国の対応交差点で

    高度化PICS が整備された交差点で受信できます。

  • 色に頼らない

    図形と文字でも示します。配色は 3 種類から選べます。

  • 読み上げの例：「1 番、青。進めます」

    声で伝える

    VoiceOver で、信号ごとに読み上げます。

  • 8段階

    残りの目安

    信号機が送る目安です。秒数ではありません。

  • 受信するだけ

    信号機には何も送りません。

  • 機能としくみ
  • 対応交差点と動作環境

表示は補助情報です。渡る前に、必ず実際の信号と周りを確かめてください。
