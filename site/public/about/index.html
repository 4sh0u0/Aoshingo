このアプリについて

信号機の電波を、
受け取るだけ。

視覚に障害のある方、色の見え方に違いのある方、横断に時間がかかる方の「いま渡れるか」の判断を補助することを目指した、非公式のオープンソースアプリです。

しくみ

  1. 信号機が発信する

    高度化PICS（歩行者等支援情報通信システム）の交差点では、信号機が交差点名や歩行者用信号の状態を Bluetooth Low Energy で発信しています。

  2. iPhone で受信する

    Aoshingo は、この公開の電波を受信するだけです。信号機に何かを送ったり、操作したりすることはありません。

  3. 画面と読み上げで示す

    受信したデータを解析して、信号ごとの状態と残り目安を、色・図形・文字と VoiceOver の読み上げで示します。

特長

  • 画面表示中のリアルタイム受信

    最大 6 つの歩行者用信号の状態と「残り目安」（8 段階）を表示します。iOS の制約により、アプリが画面に表示されている間だけ受信できます。

  • 色だけに頼らない表示

    青・青点滅・赤を、色に加えて図形・文字・破線の枠で示します。配色は「標準」「色覚サポート」「モノクロ」から選べます。

  • 安全側に倒した判定

    赤に近づく変化はすぐに、青に変わる変化は 2 回続けて一致したときだけ反映します。5 秒間更新がなければ「更新なし」と表示し、古い色は出しません。

  • VoiceOver に対応

    各信号をまとめて読み上げます。画面カーテンを使えば、画面を暗くしたまま受信を続けられます。

  • デモと記録の再生

    信号の近くにいなくても、デモで画面を確かめられます。受信データの記録と再生もでき、どちらも実際の受信と同じ処理を通ります。

  • 日本語と英語

    アプリの表示と読み上げは、日本語と英語に対応しています。

使い方と表示の見かたは「使い方」にまとめています。

対応交差点と動作環境

対応交差点
高度化PICS が整備された交差点（全国で約 600 か所）。設置場所は e-Gov データポータルの「高度化PICS整備交差点_csv」で公開されています。それ以外の交差点では何も受信しません。
対応機種
iOS 18 以降の iPhone（iPhone XS / XR 以降）
必要なもの
Bluetooth。アカウント登録は不要です。
入手方法
開発中のため、まだ配布していません。TestFlight での試験配布や App Store での公開を始めたら、このサイトでお知らせします。開発者の方は GitHub のソースコードから Xcode でビルドできます。

実測データの提供（任意）

信号の周期や、どの番号がどの横断歩道かを調べるため、受信したデータの提供をお願いしています。

選べます
初回起動時に、協力するかどうかを選べます。どちらを選んでも使える機能は同じで、設定画面でいつでも変更できます。協力しない場合、受信したデータを端末の外に送信しません。
送るもの
交差点 ID、受信した信号データ、信号が変わった時刻、5 dB 単位の電波強度、8 方位に丸めた方向など
送らないもの
利用者の現在地（緯度・経度）、機種、OS のバージョン、言語・地域、広告 ID、氏名・メールアドレスなどの個人情報。サーバーのプログラムは IP アドレスを記録しません。

送信のタイミングや保存期間など、くわしくはプライバシーポリシーをご覧ください。

オープンソース

Aoshingo は Apache License 2.0 で公開しているオープンソースのアプリです。アプリ、実測データを受け取るサーバー、このサイトのソースコードは、すべて GitHub で見られます。Issue と Pull Request を歓迎します。

対応交差点で受信した記録は、アプリの改善にとても役立ちます。協力いただける方は「現地確認の手順」をご覧ください。

謝辞

高度化PICS の解析は、yumu19/ble-pics-viewer（MIT License, Copyright (c) 2025 Tsubasa Yumura）の解析仕様と実装を参考に、Swift で再実装したものです。受信方法と解析結果を公開してくださった作者に心より感謝します。

法令に関する注記

高度化PICS の Bluetooth 信号は、交差点の信号制御機から不特定多数に向けて発信される公開の電波で、個人を識別できる情報や秘匿性のある通信内容は含まれていません。本アプリはこれを受信するだけで、信号機に対して送信・改変・再送信・妨害を行う機能は一切ありません。「信GO!」の青時間延長のような、信号機への要求を送る機能も実装しません。（法的な助言ではありません。）
