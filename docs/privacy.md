# プライバシーポリシー（草案）

> [!NOTE]
> この文書は pre-alpha（開発中の試験版）段階の草案です。TestFlight や App Store で配布する前に見直します。変更の履歴は、このリポジトリの Git 履歴で確認できます。

- 対象：iOS アプリ「Aoshingo（青信号）」と、実測データを受け取るサーバー（`server/`）
- 運営者：Aoshingo の開発者（GitHub：[4sh0u0](https://github.com/4sh0u0)）
- 制定日：2026 年 11 月 10 日（草案）

## 1. 基本方針

- アカウント登録は不要です。広告、アクセス解析、トラッキング、第三者の SDK は使っていません。
- 受信したデータは、初期状態では端末の外に送信しません。
- 端末の外に送信するのは、利用者が「実測データの提供に協力する」を選んだ場合の、下の「4. 実測データの提供」に書いた情報だけです。

## 2. 端末の中だけで扱う情報

| 情報 | 使い方 |
| --- | --- |
| 受信した Bluetooth 信号（高度化PICS） | 信号の状態を表示するために、メモリ上で扱います。受信のみで、信号機には何も送信しません。 |
| 受信データの記録ファイル | 設定で「受信データを記録する」をオンにしたときだけ作ります。端末内（アプリの書類フォルダ）に保存し、利用者が共有しない限り端末の外に出ません。位置情報は含まず、送信機は E1、E2… と表記します。 |
| 設定 | 表示の配色、画面を消さない設定、実測データの提供の選択などを端末内に保存します。 |

アプリを削除すると、これらはすべて端末から削除されます。

## 3. 位置情報

- 位置情報の利用許可は、実測データの提供に協力している場合だけ求めます。協力しない場合は求めません。
- 位置情報は、交差点から見たおおまかな方向（8 方位）を端末内で計算するためだけに使います。緯度・経度そのものは保存も送信もしません。
- 許可しなくても、すべての機能を使えます。その場合、方向は「不明」として送信します。

## 4. 実測データの提供（任意）

初回起動時に協力するかどうかを選べます。どちらを選んでも、使える機能は同じです。設定画面でいつでも変更できます。

### 送信する情報

協力している場合だけ、アプリが実際の信号を受信している間に、次の情報を送信します。デモや記録ファイルの再生中のデータは送信しません。

| 情報 | 内容 |
| --- | --- |
| 交差点 ID | 信号機が発信している 8 桁の ID |
| 受信した信号データ | 信号機が発信しているデータそのもの（交差点名、交差点の位置、信号の状態など）。間引いて送信します。 |
| 信号が変わった時刻 | 信号ごとの状態の変化（例：赤 → 青）と、その時刻（秒単位） |
| 電波強度 | 5 dB 単位に丸めた値 |
| 方向 | 交差点から見た利用者の方向と、端末の向きを、それぞれ 8 方位に丸めた値 |
| 送信機の情報 | Service UUID と、送信機の数 |
| アプリのバージョン | 例：`aoshingo-ios/0.1.0` |

### 送信しない情報

緯度・経度、機種、OS のバージョン、言語・地域、広告 ID、端末やインストールを識別する ID、氏名・メールアドレスなどの個人情報は送信しません。

### 送信のタイミング

受信中はおよそ 1 分ごとに、アプリを閉じたときにも、未送信のデータをまとめて送信します。1 回の送信に含めるのは最大 10 分間のデータで、送信同士を結び付ける情報は付けません。送信できなかったデータは端末内に最大 50 件まで保存し、6 日を過ぎたものは送信せずに削除します。

通信内容と形式の詳細は [送信 API の仕様](field-data-api.md) をご覧ください。

## 5. 不正なデータを防ぐ仕組み（App Attest）

偽造されたデータの混入を防ぐため、Apple の App Attest を使い、送信元が正規の Aoshingo アプリであることを確認します。

- 協力をオンにすると、アプリは端末の安全な領域（Secure Enclave）に鍵を作り、Apple のサーバーで証明を受けます。この処理には [Apple のプライバシーポリシー](https://www.apple.com/legal/privacy/) が適用されます。
- 鍵の ID（keyId）は、鍵の登録と送信用トークンの取得のときだけ開発者のサーバーに送ります。サーバーは鍵の ID と公開鍵を、実測データとは別の場所に保存し、実測データとは結び付けません。
- 送信用トークンには鍵の ID を含めません。協力をオフにすると、アプリはこの鍵を破棄します。

## 6. サーバーでの扱い

- サーバーは [Cloudflare Workers](https://workers.cloudflare.com/) と D1 データベースで運用しています。
- 通信を届けるために Cloudflare は IP アドレスを処理しますが、サーバーのプログラムは IP アドレスや国などを示すヘッダーを読まず、記録もしません。アクセスログやトレースの記録は無効にしています。Cloudflare 自身の扱いについては [Cloudflare のプライバシーポリシー](https://www.cloudflare.com/privacypolicy/) をご覧ください。
- 受け取った日は「日」単位でだけ記録します。
- 受け取った実測データは 90 日間保存し、その後は交差点ごとの集計（信号ごとの変化の回数を時間帯別に数えたもの、電波強度と方向ごとの受信回数など）に置き換えてから削除します。集計には個々の送信を区別できる情報は残りません。集計は期限を定めずに保存します。

## 7. 利用目的

- 信号の番号（1 番〜6 番）がどの横断歩道に当たるかを確かめるため
- 信号機ごとの発信間隔、送信機の数、受信できる範囲を調べるため
- 「残り目安」の表示や、信号の判定の正確さを改善するため

集計結果を公開する場合は、事前にこのポリシーを更新してお知らせします。

## 8. 第三者への提供

実測データを販売したり、広告などの目的で第三者に提供したりすることはありません。サーバーの運用（Cloudflare）と不正防止（Apple）のために、上に書いた範囲でこれらの事業者が処理することがあります。法令に基づいて開示を求められた場合は、法令に従って対応します。

## 9. 提供の停止と削除

- 設定画面で実測データの提供をオフにすると、端末内の未送信のデータはすぐに削除され、以後は何も送信しません。
- すでに送信したデータは、利用者や端末と結び付けて保存していないため、個別に探して削除することができません。90 日後に集計に置き換えられ、個々のデータは削除されます。
